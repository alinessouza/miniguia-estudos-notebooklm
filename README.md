## 📝 Miniguia de Estudo (Entrega Final)

### 💡 Resumo Estruturado: O Superdetetive dos Dados
Imagine que a Ciência de Dados é como ser um superdetetive em uma grande missão para resolver mistérios:
*   **Juntar as pistas:** O primeiro passo é coletar informações (dados) espalhadas por todo lugar, como nomes, idades ou números.
*   **Organizar a bagunça:** Depois, você limpa e organiza essas pistas para jogar fora o que não serve, separando os brinquedos bons dos quebrados.
*   **Usar ferramentas especiais:** O detetive usa gadgets incríveis como o SQL (para abrir baús de informação), o Python (o robô assistente que segue ordens) e o Power BI (o caderno de desenhos encantado que cria gráficos).
*   **Dar a resposta final:** No fim, você usa as pistas para ajudar as pessoas a tomarem decisões inteligentes.

### 📖 Glossário (Dicionário para Iniciantes)
*   **SQL (Linguagem de Consulta Estruturada):** É uma língua especial para "conversar" com os computadores e encontrar informações guardadas em grandes armários digitais chamados bancos de dados.
*   **Python:** Uma linguagem de programação usada para dar ordens ao computador. Ela é famosa por ser fácil de ler e aprender, quase como escrever em uma língua comum.
*   **Power BI:** Uma ferramenta que funciona como um tradutor visual. Ela pega listas enormes e chatas de números e as transforma em desenhos coloridos e gráficos interativos (dashboards).

### 🚀 3 Passos Práticos para Começar Hoje
1. **Aprender SQL e criar um projeto pessoal:** Criar um banco de dados da própria casa (como compras de mercado ou gastos mensais) para treinar.
2. **Dominar a linguagem Python para análise:** Usar sua escrita simples para aprender a processar grandes quantidades de informações.
3. **Praticar a visualização de dados com o Power BI:** Instalar a versão gratuita (Power BI Desktop) e treinar a transformação de listas em gráficos que ajudam empresas a tomar decisões.
